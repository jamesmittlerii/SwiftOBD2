# flutter_obd2

A complete port of SwiftOBD2 to Dart/Flutter, providing an easy-to-use interface to communicate with ELM327 OBD2 adapters over BLE and Wi-Fi.

## Features

- **Connection Management:** Establishes connections to the OBD2 adapter via Bluetooth or Wi-Fi.
- **Command Interface:** Send and receive OBD2 commands for powerful interaction with your vehicle.
- **Data Retrieval:** Supports requests for real-time vehicle data (RPM, speed, etc.) using standard OBD2 PIDs.
- **Diagnostics:** Retrieves and clears diagnostic trouble codes (DTCs).

## Getting started

Add `flutter_obd2` to your `pubspec.yaml`:

```yaml
dependencies:
  flutter_obd2: ^0.1.0
```
